# Maré

App de acompanhamento do ciclo menstrual, com versão Ela e Ele.

- O app fica em https://mare-5417d.web.app
- `app.html`: o app. O endereço acima busca este arquivo a cada abertura, então mudanças aqui aparecem sem publicar de novo.
- `firebase/`: projeto do Firebase (site, regras do banco e avisos). Publicado pelo Cloud Shell só quando as regras ou os avisos mudam.

Nenhum dado pessoal fica neste repositório. Os registros ficam no Firebase, protegidos por login.
